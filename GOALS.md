## Not done, on purpose or not yet

- **More hardware.** One board and panel so far: an ESP32-C3 with a round GC9A01, flashed by Michael. Other panels' display config (inversion, red/blue, offsets) is all toggles, but expect to tune it once. Touch hasn't met a real panel: the dev kits come from their published pinouts, and a resistive panel's raw range and orientation vary from module to module.
- **Screen sizes** work but are rough enough that Michael suggested dropping them. They're behind a setting until that's decided.
- **Touch calibration on the device.** LovyanGFX can calibrate a resistive panel by having you tap its corners; Kiln takes the raw range as numbers instead.

## Review log

- **Review 1, after the first milestone.** The `pio run` build surfaced LVGL 9.6 deprecations (`lv_subject_init_*`, `lv_obj_bind_*_if_*`, `lv_obj_add_flag`). The generated code moved to `lv_subject_create`, `lv_obj_set_hidden()` and friends, plus Kiln's own comparison binders, and the clang checks now treat deprecations as errors. Steiger caught an integration test reaching into another feature's internals; it moved to the `app` layer. The budget estimator was recalibrated against the real build (it had assumed the whole 4 MB chip instead of the 1.25 MB app partition).
- **Review 2, a fresh-eyes code review** (a separate agent given the code, not my conclusions) found 12 defects, most reproduced on the wasm LVGL or with clang. All 12 are fixed, each with a regression test:
  1. A hostile `.kiln` could inject `platformio.ini` sections (`upload_command` = shell on Build). Board ids are validated on open and at export, names are flattened, and every value that reaches C is checked (catalog enums, `#rrggbb`, finite numbers, known style props, comment-safe text).
  2. A restored autosave counted as saved, so New/Open could drop work silently. It now stays marked unsaved, and closing asks first.
  3. Timelines with 3+ keyframes, or alternating, froze: LVGL re-applies pending segments' start values (`early_apply`). Segments are emitted in time order with early apply only on each track's first. Tested on the wasm LVGL.
  4. Re-exporting after renaming a screen left the old file in place, and the link failed. Stale generated files in `src/ui` are removed (only ones with Kiln's header).
  5. C names could collide with `ui_setup()`, `<screen>_create()` or string buffers. Those are reserved, plus every derived form.
  6. Arc min = max divided by zero in LVGL, and the trap froze every canvas for good. Ranges are repaired at compile time, and any trap now resets the runtime and rebuilds the canvas and Play.
  7. Animation delays were ignored on replays and first triggers (LVGL only applies them to finished timelines). Autoplay and Play actions go through `kiln_obj_add_play_event`.
  8. Deleting Home could leave only the Components screen. The last real screen can't be deleted.
  9. Custom C from before subjects became pointers (`&ui_var_x`) no longer compiled. Files are migrated on open.
  10. `pio run` could hang on a non-UTF-8 byte. The output is now decoded loosely.
  11. The flex reorder drop line was drawn in the wrong place, and reversed flows reordered backwards. Fixed.
  12. A control character before a hex digit broke a C string literal. The literal is now split.
- **Review 3, Michael's first hands-on round** (2026-11-07), after flashing the thermostat sample:
  1. The export dialog's build log drew over the code. Fixed, and builds no longer live in a dialog at all: they run in the background with an output panel or window (G10).
  2. Closing the window on macOS quit the app, aborting a flash. It now hides; the Dock icon brings it back, and quitting asks if a build is running.
  3. The SPI clock didn't stick. Escape in a field reverted it and closed the dialog in one keypress, and every sample brought its own board settings. Fields commit when they unmount, Escape only reverts the field, and new projects start on the last hardware set up.
  4. Board dialog hierarchy: sections with summaries, a dev kit first, and the generated platformio.ini on show.
  5. No serial monitor: added, sharing the port with uploads.
  6. A layer moved off its screen became invisible and unclickable. It shows as an outline outside the screen that can be dragged back.
  7. The dot grid was noise nothing snapped to: replaced by a pixel grid when zoomed in.
  8. Light theme: Ayu Light, following macOS.
  9. "I don't know what this is, menu not populated": the ◆ logo, which looks like Figma's main-menu button but did nothing. It opens a main menu now, with a chevron to say so. Along the way, the inspector's folded sections got a chevron (they read as empty headings), and the menu bar got File, View, Board and Help menus.
  10. A home page and tabs per project, like Figma (G16).
  11. Screen sizes: behind a setting, not removed (G13).
- **Review 4, Michael's second round** (2026-11-08):
  1. "It does NOT want to remember 160 for SPI clock." 80 MHz is as fast as an ESP32's SPI bus goes, and the field snapped back without a word. Number fields now say "max 80" when they cap what was typed (and no longer leave "160" on show when the stored value didn't change), and the hint gives the reason.
  2. The ESP32-2424S012 read as 1 MB of flash instead of 4 MB: the meter showed the default table's 1.25 MB app partition. 4 MB ESP32s now build with `huge_app.csv` (3 MB for the app, no OTA), checked with `pio run`, and the Memory section says how much of the chip that is.
  3. The insert bar floats at the bottom of the canvas, like Figma's toolbar.
  4. Zoom moved to the top right of the canvas.
  5. Prototype noodles crossed and doubled back. They now leave towards their target, enter the side facing their source, spread out on a shared side in source order, and keep a lane apart when two screens link both ways.
  6. The serial port and baud pickers were unstyled native selects. They use the shared Select.
  7. "Misalignment kills me": the traffic lights, home icon and tab sat on three different lines. The tab strip is now Figma's (full-height cells split by hairlines) and `trafficLightPosition` puts the lights on the same centre, measured from a screen capture of the running app: every item within a point of 18.5.
  8. ⌥-drag duplicates the selection and drags the copies, like Figma (one undo step; in auto layout it drops a copy). Ignoring snapping moved from ⌥ to ⌃. Along the way: ⌘D had never worked, because cloning a node inside an edit handed `structuredClone` an immer Proxy. `cloneNode` unwraps drafts, and duplicate has a test.
